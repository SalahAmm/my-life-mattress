# Stock screen grouped by supplier

The Stock screen is grouped by fournisseur (supplier header rows with product counts), not by product category as the reference prototype shows. Each product row keeps its category badge; variants list price, stock status, and quantity underneath.

The owner thinks of inventory as "Rafik's stock / Ahmed's stock" — who he buys from matters more than product type for stock management. Categories still drive the counter's filter tabs, so both dimensions exist; only the Stock screen's grouping changed. Employees never see this screen at all.

# Brand visual identity: navy/blue/gold, square corners, reference-driven

The UI follows the reference prototype's visual system — navy sidebar, royal-blue primary actions, gold reserved for the logo and highest-priority action, cool gray workspace, white surfaces, radius 0 — instead of the shadcn "Sera" preset defaults the scaffold inherited (serif Playfair headings, uppercase tracked labels, warm taupe palette, rounded corners). Inter/Nunito Sans for French, Noto Sans Arabic for Arabic, self-hosted.

This is the brand; the cost of relocating it later is re-skinning every screen. The Sera preset was a scaffold artifact, not a chosen direction.

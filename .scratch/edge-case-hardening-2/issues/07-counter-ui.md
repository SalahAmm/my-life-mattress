# 07 — Counter UI

**What to build:** The counter blocks confirming an empty cart, merges duplicate lines, caps quantities at sane bounds, shows a no-results state for searches, and lets an out-of-stock variant be added (sur commande).

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Empty cart: confirm disabled or blocked with a message
- [ ] Duplicate line: adding the same variant increments the existing line
- [ ] Search with no matches shows a no-results state
- [ ] Out-of-stock variant can be added and sold

# Settings + Guide Spec

Settings effort per the roadmap + brief: make every Settings tab real, then the in-app Guide.

## Scope

1. **Utilisateurs tab** — the missing piece: create employee accounts (username + password), list users, reset passwords, deactivate accounts. Owner-only. Guards: unique usernames, cannot deactivate yourself, cannot deactivate the last active owner.
2. **Données tab** — backup the database to a chosen location; restore from a backup file (with warning; data replaced on restart).
3. **Guide page** — replace the placeholder with the real usage guide (FR/AR).
4. General/Payment/Printer tabs: mostly already covered by the existing Receipt + Dimension presets tabs (store name, logo, deposit percentages, receipt toggles, dimension presets, printer = system). Their content is confirmed sufficient.
